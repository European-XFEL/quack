Quack documentation
===================

This repository contains software used to reconstruct information about FEL time and energy after angular streaking.
Being able to perform this reconstruction depends on the simulation of the photo-electron propagation from a FEL basis set,
which is done in the `QuackSim`_ Julia package.

Check instructions in `QuackSim`_ for how to simulate it in details, or see the quick start introduction
below for a summary.

.. _QuackSim: https://git.xfel.eu/machineLearning/quack-sim
